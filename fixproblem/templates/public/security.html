Security information

What is implemented in this version, and what is not. We do not claim any certification.

Implemented

  • Passwords stored only as salted scrypt hashes; sign-in lockout after 5 failures in 10 minutes.
  • Role permissions enforced on the server for every request.
  • Private workspaces: each customer’s data is stored in its own database file, and workspace membership is checked on every request.
  • Customer emails masked for lower roles; search input sanitised.
  • Uploads checked for type and size; post-login redirects limited to this site.
  • Card details never reach the application (Stripe Checkout or demo mode).

Not yet implemented

  • Team invitations and per-workspace roles.
  • Email verification, password reset and multi-factor authentication (Stage 4).
  • CSRF tokens on all forms and hardened production cookies.
  • Automated backups with a tested restore procedure and external monitoring.

To report a security issue, use the contact form.
